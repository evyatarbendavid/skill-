## Skills available in this session

These live in `.claude/skills/` and load automatically — no install
step. Bootstrapped from the `99` repo via `scripts/bootstrap-skills.sh`.
See `THIRD_PARTY_NOTICES.md` for where each came from and its license.

- **ui-ux-pro-max** — UI/UX design intelligence: styles, color palettes,
  font pairings, UX guidelines, motion presets, across 22 stacks.
- **ui-styling** — building UI with shadcn/ui + Tailwind, accessible
  components, dark mode, theming.
- **design** — logos, corporate identity, icons, social assets, banners.
- **design-system** — design tokens (primitive -> semantic -> component),
  component specs.
- **brand** — brand voice, visual identity, messaging, consistency.
- **banner-design** — banners for social/ads/web/print.
- **slides** — HTML presentations with Chart.js.
- **frontend-design** (Anthropic) — distinctive, non-templated visual
  design direction and typography for new UI.
- **watch** (`/watch`) — watch a video (URL or local file): downloads it,
  extracts frames, transcribes, and hands it to Claude to analyze.
- **no-ai-slop** — edit drafts to sound less AI-generated, or detect
  AI-slop patterns without rewriting.

An MCP server for Playwright (real browser automation) is also wired
up in `.mcp.json` — prompts for approval on first use per session.
